# SimpleDBDB

A learning project where I build a simple key/value database in Python by
following the [DBDB: Dog Bed Database](https://aosabook.org/en/500L/dbdb-dog-bed-database.html)
chapter from *500 Lines or Less*.

## What I plan to do

- Read through the chapter and rebuild DBDB step by step
- Understand how data is stored on disk and survives crashes
- Learn how the binary tree storage works without keeping everything in RAM
- Write notes and tests as I go
- Maybe add my own improvements once the basics work
